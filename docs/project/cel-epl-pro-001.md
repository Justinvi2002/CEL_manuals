# Projects

## **Project principle.**
Project: Principle
A project in EPLAN serves as a database that contains not only project pages but also all essential master data used within the project, including symbols, plot frames, forms, and parts data. Thus the project file (*.elk) belongs to a project, as well as the directory where the database and the project-related master data are stored. 
Project files can have different file suffixes, e.g.:

1. .elk: Standard project
2. .elp: Zipped project
3. .elr: Completed project / reference project.

## **Basic Project.**
In EPLAN, a Basic Project serves as a template or starting point for new projects. It contains predefined settings, structures, and essential master data that can be reused to streamline project creation.

A Basic Project typically includes:

* Standard page structures and templates
* Symbols, plot frames, and forms
* Parts data and macros
* Preconfigured settings for layers, numbering, and display etc..

Using a Basic Project helps ensure consistency and reduces setup time when creating new projects in EPLAN.

## **Create new projects.**
The following sections describes how to create new projects.

1.	Select the following commands: File > New.
2.	Specify a project name in the Project name field of the dialog Create project.
3.	Click   in the Storage location field and specify the directory where the project is to be stored in the subsequent dialog. Default project storage location is E:\System\Projects\CEL\2025. Refer User-Defined File Locations
4.	Click   in the Basic project field and switch to the directory where the template is located in the Select basic project dialog.
5.	Select the desired basic project and click [Open].
6.	Click [OK].
